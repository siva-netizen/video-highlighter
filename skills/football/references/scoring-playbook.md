# Football scoring playbook (detailed)

## Rank high

- Goals (open play, headers, long range)
- Penalties scored; penalty shootout deciders
- Outstanding saves, double saves, point-blank denials
- Red cards, second yellow, major VAR overturns with clear outcome
- Counter-attacks ending in shot on target or goal

## Audio cues

- Commentator shout: "GOAL!", sustained crowd cheer
- Volume step-change on "unbelievable", "world class"

## Skip (score ≤3)

- Throw-ins, goal kicks, routine offside flags without shot
- Touchline tussles without card
- Extended tactical talk with no match action language
- Replay-only segment if equivalent live moment already picked

## Editing rules

- Goals: include immediate build-up when commentary references pass or run
- Keep through first crowd peak after goal (post_roll default 8)
- Diversify across halves when target duration > 90s

## Keyword hints

goal, scores, penalty, red card, save, header, free kick, counter, assist, var, woodwork, nutmeg, tackle
