# Cricket scoring playbook (detailed)

## Rank high

- Wickets: bowled, caught, lbw, run out, stumped, hit wicket
- Sixes and boundary sixes; fours with clear commentator lift
- Milestones: fifty, century, five-wicket haul
- Match-turning spells ending in wicket or double wicket
- Sharp crowd roar synchronized with commentator pitch rise

## Audio cues

- Sudden loudness with "gone", "massive", "what a shot", "into the crowd"
- Sustained crowd after boundary or wicket
- Partner/lead commentator overlap (excitement signal)

## Skip (score ≤3)

- Drinks, tactical timeouts, super-over admin without delivery
- DRS wait with no outcome in window
- Sponsor reads, studio analysis without match footage context
- Routine singles and dot balls unless part of same-over wicket collapse

## Editing rules

- Wicket clips: prefer delivery through first reaction beat (use pre_roll from metadata, extend if text starts mid-delivery)
- Do not double-count same ball (live angle + slow-mo replay) — keep earlier/live window
- Spread picks across innings phases when target duration allows

## Keyword hints

wicket, out, six, four, caught, bowled, lbw, century, fifty, dropped, run out, stumped, no ball, free hit, hat-trick
